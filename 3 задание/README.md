# Задача 3. Анализ файлов и отчёт

Написать скрипт `file_report.sh`, который:

- проходит по всем файлам в `lab_data` через `for file in lab_data/*`
- для каждого файла выводит:
  - имя файла
  - размер в байтах
  - время последнего изменения в человекочитаемом виде
  - тип файла через `stat -c "%F"`
- сохраняет отчёт в файл `report.txt`

Дополнительно:

- отсортировать файлы по размеру от меньшего к большему
- вывести топ-3 самых больших файла
