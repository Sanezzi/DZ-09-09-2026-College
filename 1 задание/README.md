# Задача 1. Генератор тестовых файлов

Написать скрипт `make_test_files.sh`, который:

- создаёт директорию `lab_data`
- внутри неё создаёт 3 файла:
  - `small.txt` — 10 строк текста
  - `medium.txt` — 500 строк
  - `large.txt` — 10 000 строк
- выводит размеры файлов через `stat --format="%s"`

Требования:

- использовать только Bash-встроенные команды и утилиты: `echo`, `seq`, `>`, `>>`, `mkdir`, `stat`
- не использовать сторонние языки программирования
