# Задача 2. Безопасное копирование и проверка

Написать скрипт `safe_copy.sh`, который:

- принимает 2 аргумента: исходный файл и целевой файл
- проверяет:
  - существует ли исходный файл через `test -f`
  - есть ли права на чтение исходного файла
  - если целевой файл существует, выводит предупреждение и не перезаписывает его без флага `-f`
- копирует содержимое построчно через цикл `while read`
- в конце выводит размер обоих файлов и сравнивает их

Примеры запуска:

```bash
./safe_copy.sh small.txt small_copy.txt
./safe_copy.sh medium.txt medium_copy.txt -f
```
